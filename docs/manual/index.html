luil 설명서

C++20으로 쓴 UI 프레임워크 luil의 사용 설명서다. 핵심 개념, 컴포넌트를 만드는 법, 공개 API 전부를 한곳에서 찾는다. 설명마다 원문 코드의 줄로 이어진다.

버튼을 누르면 점이 세 스레드를 지나간다.
UI thread가 받은 입력은 input thread가 클릭으로 판정하고, 앱 메시지가 되어 logic thread로 간다. logic은 상태를 바꾸고 새 불변 tree를 지어 게시한다. 그러면 UI thread가 그것을 그린다. 흐름은 한 방향이다 — luil 개요와 스레드 모델 문서가 이 그림을 풀어 쓴다.

설명서 구성

처음이라면 개요와 핵심 개념을 차례로 읽는다. 무엇을 만들려는지 알고 있다면 컴포넌트 문서로 바로 가고, 필드 하나·함수 하나가 궁금하면 API 찾아보기나 위 검색 칸(/)을 쓴다.

읽는 법

문서는 개념 → 만드는 법 → 설정과 메시지 → 키보드·접근성 → 플랫폼 차이 → 함정 → 자주 묻는 질문 차례로 쓴다. 필요한 칸만 골라 읽어도 되도록 칸마다 홀로 선다.

누구를 위한가

  • luil로 앱을 만들려는 C++ 개발자 — 화면을 짓고, 입력을 받고, 상태를 바꾸는 법
  • 특정 컴포넌트를 쓰다 막힌 사람 — 트리 뷰의 펼침 상태, 여러 개 선택, 끌어 옮기기
  • 불변 tree, 스레드 경계 메시징, UAX #14, 닫힌 해 스프링 같은 기술이 궁금한 사람

무엇이 들어 있나

  • 코드 읽기: 오른쪽 해설의 차례를 넘기면 왼쪽 원문에서 그 줄이 밝아진다
  • 실습 창: luil의 규칙을 브라우저로 옮겨 직접 눌러 본다. 왼쪽 위 단추로 처음 상태로 돌린다
  • API 찾아보기: 공개 헤더의 기호 5,581개를 주석과 선언 원문 그대로 보인다

무엇을 믿어도 되나

  • 원문 발췌는 기준 커밋의 파일에서 줄 번호로 기계적으로 채웠다. 머리의 링크가 GitHub의 그 줄이다
  • 줄 나눔·스프링·실행 취소 실습의 이식본은 원본 C++을 컴파일해 무작위 입력으로 대조했다
  • 헤더가 설계 문서보다 앞선다. 이 설명서를 쓰며 네 플랫폼을 실행하지는 않았다

기능 지도

luil의 기능을 서로 겹치지 않게 157개로 나눈 지도다. 23개는 뼈대 개념이고 134개는 기능이다. 항목마다 대표 공개 헤더와 설계 문서로 이어지고, 이 설명서가 다루는 것은 그 문서로 이어진다.
