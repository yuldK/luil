# 가상 목록의 격자(타일) 모드와 가운데 맞춤 들이기

사진·파일 보기는 같은 모델을 한 줄에 하나(목록)로도, 한 줄에 여럿(격자)으로도 보인다. 앱이 한 행에 타일 N개를 묶어 격자를 흉내 내고, 전환 때 스크롤 값을 손으로 다시 셈하고, 지금 항목을 가운데로 들이려고 배치 중에 계산하지 않도록 `virtual_list_element`에 격자 모드와 들이기 자리를 둔다.

공개 형식은 [virtual_list_element.h](../include/luil/ui/virtual_list_element.h)의 `virtual_list_config::columns`·`minimum_column_width`·`reveal`과 `virtual_list_grid_columns`·`virtual_list_grid_offset_keeping`·`virtual_list_reveal_offset`이다. 목록 자체의 계약은 [virtual-list-design.md](virtual-list-design.md)다.

## 격자 모드

- `columns`(고정 열 수)나 `minimum_column_width`(칸 폭이 이 값 이상인 만큼 — 창 폭에 따라 열이 바뀐다)를 정하면 격자다. 둘 다 0이면 지금처럼 한 줄에 하나다. `minimum_column_width`가 앞선다.
- 항목은 줄 차례로 칸을 채운다(0, 1, 2 / 3, 4, 5 …). 칸 폭은 내용 폭을 열 수로 나눈 것이고, 칸 높이는 모두 `row_height`다 — 격자에서는 `virtual_list_item::height`를 보지 않는다.
- 열은 막대를 뺀 내용 폭으로 센다. 막대가 서는지는 내용 높이가 정하고 그것은 열 수가 정하므로, 막대 없이 세어 넘치면 막대 폭을 빼고 다시 센다(열이 줄면 더 넘칠 뿐이라 한 번이면 된다).
- 가상화는 줄 단위다. 창에 걸치는 줄(과 `overscan`만큼 위아래 줄)의 칸만 짓는다. 백만 칸에서도 한 화면만 짓는다. 커서 칸·고른 칸은 지금처럼 창 밖에서도 짓는다.
- 계층(`set_expanded`)과 함께 쓰지 않는다 — ←/→가 칸 이동이 된다.

### 키보드

| 키 | 격자에서 |
| --- | --- |
| ↑ / ↓ | 한 줄(열 수만큼). 첫 줄의 ↑·마지막 줄의 ↓는 제자리다 |
| ↓ (아래 칸이 빈 덜 찬 마지막 줄 위) | 마지막 항목 — 파일 관리자와 같다 |
| ← / → | 한 칸. 줄 끝에서 다음 줄로 이어진다 |
| Page Up / Down | 창에 드는 줄 수만큼. 위로 넘치면 같은 열의 첫 줄이다 |
| Home / End | 처음·끝의 활성 항목 |

- 수식 키의 뜻은 ↑/↓와 같다 — Shift는 범위(`extend`), Ctrl은 커서만 옮기기(`keep_selection`). ←/→도 `move_with`에 같은 문맥으로 간다.
- 비활성 칸에는 서지 않는다. 같은 방향의 가장 가까운 활성 칸으로 가고, 없으면 제자리다.
- 글자 찾기·Space·Enter·선택·끌어 놓기·우클릭은 목록과 같다.

### 보조 기술

목록(List)과 그 항목(ListItem)으로 읽힌다. 윈도의 파일 탐색기 아이콘 보기와 같은 관례다 — 표(DataGrid)는 칸마다 뜻이 다른 열이 있을 때의 어휘이고, 타일은 한 종류의 항목이 줄을 바꿔 늘어선 것이다. "몇 개 중 몇 번째"는 모델 차례 그대로다.

## 열 수가 바뀔 때 같은 항목 보이기

스크롤 값은 앱 상태라 목록이 바꾸지 않는다. 열 수나 줄 높이가 바뀌는 순간(목록↔격자 전환, 창 폭 변화) 앱이 `virtual_list_grid_offset_keeping(offset, 옛 열, 옛 줄 높이, 새 열, 새 줄 높이)`로 새 값을 정하면 창 맨 위 줄의 첫 항목이 새 배치에서도 맨 위 줄에 선다. 줄 안에서 흘러간 만큼은 줄 높이의 비율로 옮긴다.

창 폭으로 열을 정하는 격자에서 앱이 같은 열 수를 얻으려면 `virtual_list_grid_columns(config, 내용 폭)`에 목록과 같은 폭(막대가 설 때 `scroll_area_bar_width`를 뺀 폭)을 준다.

## 가운데 맞춤 들이기

`reveal = virtual_list_reveal::center`면 키보드가 커서를 창 밖으로 옮겼을 때 그 항목(격자면 그 줄)을 창 가운데로 들인다. 기본(`nearest`)은 지금처럼 가까운 가장자리에 붙인다. 이미 다 보이면 흘리지 않는다. 끝 근처에서는 흘릴 수 있는 범위 안으로 다듬는다.

앱이 직접 들이고 싶으면(사진 보기에서 다음 사진으로 넘길 때) `virtual_list_reveal_offset(구간 시작, 길이, 지금 값, 창 높이, center)`가 절대 스크롤 값을 준다 — `scroll_to`로 그대로 보낸다.

- 데모 "목록과 트리" 페이지의 가상 목록 "격자로 보기"(전환해도 맨 위 항목이 남는다).
