UI thread가 받은 입력은 input thread가 클릭으로 판정하고, 앱 메시지가 되어 logic thread로 간다. logic은 상태를 바꾸고 새 불변 tree를 지어 게시한다. 그러면 UI thread가 그것을 그린다. 흐름은 한 방향이다 — 1강과 2강이 이 그림을 풀어 쓴다.
